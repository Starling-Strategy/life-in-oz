KEEP THE FACTS STRAIGHT
Each brief lists episodes with a status:
- happened: describe it as done, with a concrete detail and a modest result.
- planned: it stays a plan, request, offer or intention. Never write it as done.
- hearsay: it reaches the document secondhand; keep the attribution ("Hannah says neighbors told her...").
Attribute each action to the right person. A person listening, asking a question or agreeing is not doing the work. If the brief marks a CORRECTION, the document must clearly correct the earlier account. If it marks a DISAGREEMENT, report both accounts without resolving them. Keep supplied numbers, durations, places and dates exactly, and do not add details that contradict them (if the brief says three days, never write four). Do not add outcomes the brief does not give. People talk only about the listed episodes; if the form invites more (a survey question, a panel introduction, a bio), answer with opinions, routine description or the listed episodes, never a new accomplishment, and never a different version of a listed fact. Do not recap episodes that are not in the brief.
