# Contributing

Keep the material useful, fictional and easy to reuse.

- Do not submit real private records, contact details, credentials or disguised client material. Start with invented premises.
- Label all new sources as fictional. Do not invent live links, real recordings or endorsements.
- Choose an existing collection or declare a separate scenario when roles, timelines or physical rules differ.
- Preserve released document IDs. For an intentional source revision, update hashes, affected evidence and release notes together; do not quietly repair history.
- Keep authoring premises, source documents and reference annotations distinct. A successful substring check is not a semantic review.
- Document any new generation method and third-party material. Use only material you have the right to contribute; later Oz adaptations are not automatically public domain.
- Run `python3 scripts/validate.py` and `python3 -m unittest discover -s tests -v` before proposing changes.

By submitting a contribution for inclusion, you agree to dedicate the rights you hold in it under this repository's CC0 terms. Do not contribute material whose rights you cannot dedicate. Attribution is welcome but not required by CC0.

Please report a suspected privacy or rights problem to the maintainers without reproducing sensitive material in a public issue. Propose documentation and reference-answer corrections with the exact source passage and an explanation.
